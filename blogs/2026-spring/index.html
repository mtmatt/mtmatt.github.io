總體而言，這學期過的挺有生活。儘管有各種波折，有些事情沒有做到最好，現在的我認為我願意付出一些成績、表現來換取生活品質。

事件
#

既然都這麼說了，這次當然要有不一樣的敘事方法。讓我們順著時間的長河逆流而上。

Week 17
#

這週，我與兩位朋友在盡力的完成 VM 的期末報告。我們想要在 pKVM 的基礎上新增一個目前還沒有完善的功能：SMMU + Device Passthrough。我們太晚才意識到我們的 Claude Code 是在欺騙我們。因為他真的信誓旦旦用一個資訊系學生可以理解的說明，說服我們他做得很好。

直到我上真實的機器測試才知道他根本沒有做實際的測試，所有的內容都在他的臆想中。他運用許多話術讓我們認為他做的足夠好，即便是那立刻被禁用的 Fable 5 也逃不過這樣的宿命。

雖然最後我們也沒有拿到太糟糕的成績，我還是覺得系統算是一塊目前 AI 比較不容易在沒有指導的情況下完成工作的一個領域。

Week 15 - 16
#

最讓人揪心的，大概是 CSL 自駕船競賽前一天的無奈了。我們的晶片在最後一天燒毀，並且沒有可以替換的晶片可以用。幸好期末考順利過關，不過當然我指的是我的關。

Week 13 - 14
#

這兩週的生活重心被邊緣世界 (Rimworld) 佔據了不少時間，我想我在享受那無法控制的命運。「這也許是個重大的災難，卻遠不及故事的終結。」這句話正是邊緣世界的基調。在學業上，一口氣報告了兩篇論文 (VM 口頭報告與實驗室)，同時還得硬著頭皮搞定兩個期末專題。生活中的體悟則是發現了某些氣味對自己而言，真的是無法接受的事情。

Week 9 - 12
#

發生完全意想不到的事。我居然在轉角處竟然撞見了一個人，這機率到底有多低 [1]。我們的反應真的特別有趣，認真完全不熟。

重新嘗試著跟一般人進行交流，卻有些懊惱沒能把心裡真正想表達的想法好好說出口。雖然我對我的定位還是相當了解的，我還是想至少說點話，不為了什麼。

Week 1 - 8
#

學期前半段過得挺有生活，也挺混亂。

這學期我是 DSA Judge 的 Backend Developer，我們在期初因為過年的緣故事情相當的趕。實驗室的也逐漸步入正軌，Rex VM 開始運行，Judge 系統的 race condition、金牌的規劃，全部同時擠進生活裡。那段時間像是同時開了太多分頁，每個分頁都在不斷地跳出通知，使人難以招架。

課程上，最有生活感的部分大概是茶。從酸甜苦鹹水，到開始認識臺灣產的十種茶的大分類，再到開始分辨茶乾的差異，我逐漸意識到茶的風味可以被描述、被拆解，也可以被訓練。理論上酸甜苦鹹水對我們這種年輕人來說應該要比較簡單，不過相較於其他人，我們卻不太擅長。後來我仍拿到了初級品茶師證照，也有些意外的收穫。

當然，生活也沒有因此變得悠閒。DRL 的作業、新生盃 ICPC、Judge 系統的問題回報，仍然不停追上來。另一方面，我也開始做一些實用的小工具，像是具有圖形界面的，封裝 ffmpeg 和 pandoc 等常用轉檔軟體的 swift-shifter。這是我自己做過我最常用的軟體，對於經常生產一些內容的人相當方便。不過因為我的個人電腦目前都是 Mac，所以這個工具只保證能在 Mac 上正常運行。喜歡這個軟體的人可以試著移植。

而在這些事情之外，也有一些更難分類的片段。比如和人討論人類的未來會走向何方。

朋友
#

我的朋友主要分成兩群人，一種是能夠看見他周圍世界的不足，另一種則是能看見他周圍的美好。我覺得這與悲觀/樂觀有所差異。在我的認知中悲觀/樂觀是因為看見他周圍世界的不足/美好而感到悲傷/快樂。然而他們主要是透過這樣的方式產生共鳴。

提及這點主要還是期待自己可以減少抱怨這個世界，我知道我會抱怨正是因為以我目前的能力，或甚至未來的能力都沒有機會可以撼動這個世界的矛盾與不足。也因此，我希望我可以比較專心的思考怎麼在這樣的環境限制下得到最好的生活。

其他
#

我可以清晰地感受到，在我使用語言作為思考媒介時漸漸浮現的遲滯。使用古法編程這種非遺手藝的時候靈活程度也顯著的下降。當環境迫使我使用這些生產更快速的工具時，我需要一些取捨。犧牲使用傳統方法的熟練度，去換取使用現代工具的生產力大幅度提升。

註
#
